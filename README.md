# Guomu (過目)

Website for **Guomu**, an iPhone app for checking files an AI agent made on your phone:
receive them from the share sheet, read them full screen, leave notes, and send the notes back as one piece of text.

Served by GitHub Pages at https://sona-orbit.github.io/guomu/

- Home, privacy and support pages in English, 繁體中文, 日本語, 한국어 and ไทย
- Static HTML and CSS, no build step on this repository
- Contact: sona.orbit.hi@gmail.com
