# Guomu (過目)

Website for **Guomu**, a file viewer for iPhone: Markdown, HTML, JSON, CSV, ZIP, subtitles, fonts and other files
the iPhone does not open well. Share them in, read them full screen, leave notes, and run HTML mini apps offline.

Served by GitHub Pages at https://sona-orbit.github.io/guomu/

- Home, privacy and support pages in English, 繁體中文, 简体中文, 日本語, 한국어, ไทย, Español, Deutsch, Français and Português (Brasil)
- Static HTML and CSS, no build step on this repository
- Published by Sona Orbit. Issues and pull requests are turned off.
