# Guomu (過目) — open Markdown, HTML, JSON, CSV and ZIP files on iPhone

Guomu is a file viewer for iPhone that opens the files your iPhone does not handle well: Markdown, HTML, JSON, CSV, ZIP, subtitles, fonts, certificates and more, 38 formats in all. Tap Share in any app, choose Guomu, and read the file full screen; leave notes where something needs changing, and run HTML mini apps offline. Free download, no account.

[Website](https://sona-orbit.github.io/guomu/) · [App Store](https://apps.apple.com/app/id6835101059) · [Help and FAQ](https://sona-orbit.github.io/guomu/support/) · [Privacy](https://sona-orbit.github.io/guomu/privacy/)

## Features

- **38 file formats**: documents (PDF, Word, Excel, PowerPoint, Pages, Numbers, Keynote, RTF), HTML, SVG, Markdown, CSV, TSV, JSON, GeoJSON, YAML, XML, plist, code and text, images, audio, video, SRT and VTT subtitles, ZIP, EPUB, CBZ, fonts, certificates, 3D models, ICS, VCF and EML.
- **Share it in, read it full screen**: from LINE, Mail, Safari, Files or an AI app; a ZIP opens straight to its contents. Files it does not recognize can be viewed as hex.
- **HTML mini apps**: HTML opens without running its code by default; switch to Offline mini app to use a timer, expense tracker or other small tool an AI made, without network access.
- **Notes and return slips**: mark each file to review, with notes or reviewed, then gather the open notes into one piece of text to send back to whoever made the file.
- **Save posts from a link**: author, text and first image of public Threads, X, Instagram and Facebook posts.
- **Labels are folders** in the Guomu folder of your iCloud Drive, visible in the Files app and on your Mac.
- **Free** keeps up to 10 deliveries with a banner ad; Pro removes the limit and ads. iPhone with iOS 18 or later.
