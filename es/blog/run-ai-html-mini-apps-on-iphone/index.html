Cómo usar mini apps HTML hechas con IA sin conexión en iPhone

Si le pides a una IA que haga una herramienta pequeña, como un temporizador, un control de gastos o una lista de tareas, puedes obtener un archivo HTML en pocas frases. El último paso suele ser la parte difícil: abrirlo en el teléfono, hacer que los botones funcionen y conservar los datos para la próxima vez. Pide a la IA que ponga todo en un solo archivo HTML, compártelo con Guomu y cambia a “Offline mini app” para ejecutarlo. Funciona sin conexión y sus datos se quedan en esa entrega.

Soy Sona Orbit, desarrollador independiente de Guomu (過目). Así es como uso herramientas hechas con IA en mi teléfono. Para ver los detalles sobre las funciones de Guomu, consulta este sitio y la versión 1.0 de la app (noviembre de 2026).

1. La parte difícil: abrir una herramienta hecha con IA

El HTML no sirve solo para páginas web. También puede ser un programa pequeño con botones que hace cálculos y recuerda lo que escribes. Claude, Gemini y apps de IA similares suelen crear uno a partir de una petición breve.

Lo complicado es usarlo en el teléfono. Puede ser un bloque largo de código en un chat. Incluso si lo guardas como archivo, necesitas un lugar donde abrirlo y ejecutarlo. Para que la herramienta sea útil, sus botones tienen que funcionar y sus números deben conservarse.

2. Herramientas que puedes pedirle a una IA

Las buenas opciones caben en una pantalla, tienen pocos botones y guardan datos solo para ti. Por ejemplo:

  • Un temporizador Pomodoro, para el té o de intervalos
  • Un control de gastos sencillo: anotas un importe y una categoría, y ves el total
  • Una lista diaria para beber agua, tomar medicación o practicar vocabulario
  • Tarjetas de estudio que puedes girar y que repiten las que fallas
  • Una calculadora para dividir la cuenta o un conversor de divisas (tú introduces el tipo de cambio)
  • Un selector al azar, un dado virtual o un cuadrante de turnos

3. Cómo escribir una instrucción que funcione

Además de describir la herramienta que quieres, añade estas indicaciones para que el archivo funcione en tu teléfono:

  • “Hazlo en un solo archivo HTML, con el CSS y el JavaScript dentro del mismo archivo”. Un solo archivo es más fácil de compartir y no le faltan piezas.
  • “No uses bibliotecas externas ni una CDN”. El código cargado desde internet no se ejecutará en Guomu. El código escrito dentro del archivo sí.
  • “Guarda los datos en localStorage”. Así se conserva lo que introdujiste al cerrar y volver a abrir la herramienta.
  • “Diséñalo para un iPhone en vertical, con botones grandes”.
EnfoqueEjemplo
Solo nombrar la herramienta“Hazme un control de gastos”.
Dar detalles útiles“Hazme un control de gastos. Déjame introducir un importe y elegir una categoría (Comida, Transporte u Otros). Muestra los registros de hoy y el total abajo. Hazlo en un solo archivo HTML con el CSS y el JavaScript en el mismo archivo. No uses bibliotecas externas. Guarda los datos en localStorage. Diséñalo para un iPhone en vertical”.

4. Ábrela en Guomu con Offline mini app

Cuando el archivo esté listo, toca Compartir en la app de IA y elige Guomu para recibirlo como una entrega. Luego cambia de modo:

  1. Abre la entrega. Empieza a pantalla completa. Toca el botón cuadrado de abajo a la derecha para mostrar toda la interfaz.
  2. Arriba, toca “Run mode”.
  3. Elige “Offline mini app”. La página se recarga y sus botones ya funcionan.

Guomu tiene tres modos para abrir HTML. Empieza en el modo más prudente. Debes cambiar de modo tú mismo para ejecutar código y, cada vez que abres el archivo, empieza en “Safe preview”:

ModoEjecuta códigoAcceso a internetIdeal para
Safe preview (predeterminado)NoNoInformes y documentos que solo necesitas leer
Offline mini appEjecuta el código del archivoNoTemporizadores, controles de gastos y listas
HTTPS mini appEjecuta el código del archivoPuede conectarse por HTTPS tras tu confirmaciónHerramientas que necesitan obtener datos en línea

HTTPS mini app puede permitir que una página envíe lo que escribes a otro servidor. Úsalo solo cuando confíes en el origen del archivo. “Offline mini app” basta para la mayoría de las herramientas pequeñas.

5. Conservar o borrar tus datos

Cada entrega tiene su propio almacenamiento. Los datos que una herramienta guarda en localStorage siguen ahí la próxima vez que abres esa entrega en Guomu. Otras herramientas no pueden verlos.

Para empezar de cero, toca “⋯” arriba a la derecha y elige “Clear this file's mini app data”. Esto borra los datos guardados de la herramienta, pero no elimina el archivo.

Puedes abrir el ejemplo “Focus Timer.html” en los ajustes de Guomu y cambiar a “Offline mini app” para probarlo.

6. Lo que estas herramientas no pueden hacer

Guomu limita lo que el código web puede hacer para que puedas abrir archivos de orígenes desconocidos con más seguridad:

  • El código cargado desde internet, incluidas las CDN y las bibliotecas externas, no se ejecutará. Ponlo dentro del archivo.
  • La página no puede abrir ventanas nuevas, incrustar otras páginas web ni navegar a URL externas.
  • Los formularios no se enviarán a internet.
  • La página solo puede conectarse a internet después de que cambies a “HTTPS mini app” y lo confirmes.

Si una herramienta necesita varios archivos, como imágenes o un archivo CSS aparte, pide a la IA que los empaquete en un ZIP con un index.html dentro. Comparte todo el ZIP con Guomu. Abrirá primero index.html y los archivos del mismo paquete podrán hacer referencia entre sí.

7. Dejar notas y pedir correcciones a la IA

La primera versión suele necesitar pequeños cambios, como un botón más grande o números mejor alineados. Cuando veas algo, añade una nota en Guomu que diga qué hay que cambiar y cómo. Al terminar de revisar, usa “Return slip” para reunir las notas pendientes en un solo texto. Pégalo en tu conversación con la IA y pide que lo corrija.

Envía el archivo revisado a Guomu con el mismo nombre. Se convierte en la versión 2, así que puedes comprobarlo con tus notas anteriores una por una. Explico este proceso en otro artículo.

Guomu requiere iOS 18 o posterior. La versión gratuita te permite guardar 10 entregas y tiene un banner publicitario. Pro elimina el límite de entregas y los anuncios. Tus archivos y los datos de las mini apps se quedan en tu teléfono o en tu iCloud Drive, no en mi servidor. Consulta la política de privacidad para ver más detalles.

8. Preguntas frecuentes

¿Por qué no funcionan los botones cuando abro un archivo HTML?

Guomu abre el HTML en “Safe preview” de forma predeterminada, lo que no ejecuta el código de la página. Muestra toda la interfaz, toca “Run mode” arriba y elige “Offline mini app”. La página se recarga y ya puedes usar los botones.

¿Perderé los datos guardados por una mini app?

Los datos guardados en localStorage se quedan con esa entrega y siguen ahí cuando la vuelves a abrir. Para borrarlos, toca “⋯” y elige “Clear this file's mini app data”.

¿Por qué no funciona en Guomu una herramienta hecha con IA que usa una biblioteca externa?

El código cargado desde internet no se ejecuta. Pide a la IA que cree un solo archivo HTML con todo el código necesario escrito dentro, sin usar una CDN.

¿Puede una mini app obtener datos de internet?

Puedes cambiar a “HTTPS mini app”. Guomu te pide confirmación primero. El código de la página podría enviar su contenido o los datos que introduzcas a otro servidor, así que usa este modo solo cuando confíes en el origen del archivo.
