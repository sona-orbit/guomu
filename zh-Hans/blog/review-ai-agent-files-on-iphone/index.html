在手机上请 Claude、Gemini 做的文件，怎么检查、再请它改？

在手机上请 Agent 做东西，最难的不是请它做，而是检查：文件挤在对话里看不清楚，看到要改的地方又一次只能讲一点。比较顺的做法是请它输出成文件、全屏幕看、边看边记下“位置＋要改什么”，最后把所有修改整理成一段文字一次交回，改好的第 2 版再对照上次的笔记。

我是 Sona Orbit，一个人开发过目的独立开发者。这篇是我自己在手机上检查 Agent 产出的做法；过目的功能以本站说明为准（2026 年 11 月）。

1. 请 Agent 输出成文件，不要只贴在对话里

周报、表格、简单的网页，如果直接贴在对话里，手机画面窄，表格会被挤坏，长文件也很难前后对照。请 Agent 做成文件，例如 HTML、Markdown、PDF 或 CSV，看起来会清楚很多。

提示词可以直接写：“做成一个 HTML 档给我”或“输出成 Markdown 档”。

2. 全屏幕看，一次看一件

文件做好后，用分享选单送到可以预览的地方，例如 iPhone 的“文件”App，用全屏幕打开。

Agent 一次交好几个文件时，一份一份看，看完的就标记起来，免得漏看或重看。

3. 边看边记：位置＋要改什么

看到要改的地方当下就记，不要等全部看完再回想。每一则写两件事：

  • 位置：第几段、哪一张表、哪一栏。
  • 要改什么：讲结果，不讲感觉。“第 3 列的金额应该是 12,400”比“数字怪怪的”好改。

一则只写一件事。这样 Agent 改的时候不会漏，你之后对照也容易。

4. 整理成一段文字，一次交回

看完再把所有笔记整理成一段文字，编号列出，一次贴回和 Agent 的对话。一次给完比较不会改了这里、又动坏那里，也省得来回好几轮。

写法例子
不好改“表格有点问题，再看一下”
好改“1. 第二张表第 3 列金额改成 12,400。2. 标题的日期改成 11 月 16 日。3. 结论那段删掉最后一句。”

5. 第 2 版回来，对照上次的笔记

改好的文件送回来时，拿上次的笔记一条一条对：哪几条改好了，哪几条没改或改错。没改好的留著，下一轮再交回去。

6. 我把这套流程做成了过目

上面这些用“文件”App 加备忘录也做得到，只是要在几个 App 之间切来切去。所以我做了 过目，把它们放在同一个地方：

  • 在 Agent 的 App 里按分享、选过目，文件就收进来；HTML、Markdown、PDF、图片、CSV 等 38 种格式都能全屏幕看。
  • 看到要改的地方就加一则备注；每件交付有“待看、备注、已过目”三种状态。
  • “退件单”会把还没解决的备注整理成一段文字，可以复制或分享回对话。
  • 同名文件再送进来，会标成第 2 版，方便对照上次的备注。

过目需要 iOS 18 以上，免费版可以存 10 件、有横幅广告；Pro 不限件数、没有广告。文件和备注存在你自己的 iCloud 云碟或手机里，不会传到我们的服务器，详见隐私权政策。

7. 常见问题

为什么要请 Agent 输出成文件？

手机画面窄，表格、长文件直接贴在对话里容易挤坏，也不好前后对照。做成 HTML、Markdown、PDF 这类文件，可以全屏幕看。

修改要一次交回，还是看到一条讲一条？

建议看完再一次交回，编号列出。一次给完，Agent 比较不会改了这里又动坏那里，也比较少来回。

过目怎么知道文件是哪个 Agent 做的？

iOS 不会告诉过目文件是从哪个 App 分享来的，所以标签是猜的：看网址的网域、看文件里 Agent 写的标记，猜不到就带入上次用的。收件前可以改。

过目打不开的格式怎么办？

像 SKP、DWG、RAR、7Z 这类格式打不开，过目会说明，可以转给别的 App 开，或看原始内容。
