我是 Sona Orbit，一个人开发过目的独立开发者。这篇写的是我自己在手机上用 AI 做小工具的方式；过目的功能以本站说明与 App 1.0 为准（2026 年 11 月）。

1. AI 做的小工具，卡在“打开来用”

HTML 不只是网页，也可以是一个小程序：有按钮、会计算、能记住你输入的东西。请 Claude、Gemini 这类 AI 做一个，通常几句话就有了。

麻烦在手机上。它常常只是对话里一大段程序码；就算存成文件，也要找一个能真的执行它、又让人放心的地方打开。按钮按得下去、数字记得住，这个小工具才算能用。

2. 可以请 AI 做哪些小工具

适合的是“一个画面、几个按钮、资料只给自己看”的东西，例如：

  • 番茄钟、泡茶计时、运动间歇计时
  • 简单记帐表：输入金额和类别，自动加总
  • 每日打卡清单：喝水、吃药、背单字
  • 单字卡：点一下翻面，答错的再出现
  • 聚餐分帐、汇率换算（汇率自己填）
  • 抽签、骰子、轮流排班表

3. 提示词这样写，比较能直接用

说清楚要什么之外，加上这几句，做出来的文件比较能在手机上直接跑：

  • “做成单一 HTML 档，CSS 和 JavaScript 都写在同一个文件里。”一个文件最好分享，也不会缺东缺西。
  • “不要用外部的程序库或 CDN。”从网络载入的程序在过目里不会执行，写在文件里的才会。
  • “资料存在 localStorage。”这样关掉再打开，输入过的东西还在。
  • “版面以 iPhone 直式为主，按钮大一点。”
写法例子
只说要什么“帮我做一个记帐工具”
比较能直接用“帮我做一个记帐工具：输入金额、选类别（餐饮、交通、其他），下面列出今天的纪录和总额。做成单一 HTML 档，CSS 和 JavaScript 写在同一个文件，不要用外部程序库，资料存在 localStorage，版面以 iPhone 直式为主。”

4. 用过目打开：切到“离线小应用”

文件做好后，在 AI 的 App 里按分享、选 过目，收进签收单。打开后照这样切换：

  1. 点开那一件。默认是全屏幕，按右下角的方钮叫出完整介面。
  2. 上方会有一列显示目前的模式，按“执行模式”。
  3. 选“离线小应用”，页面重新载入，按钮就能按了。

过目打开 HTML 有三种模式。默认是最保守的那一种，要执行程序得自己切换，而且每次打开都会从“安全预览”开始：

模式执行程序联网适合
安全预览（默认）不执行不连报表、文件这类只要看的页面
离线小应用执行文件里的程序不连计时器、记帐表、打卡清单
HTTPS 小应用执行文件里的程序可以连 HTTPS，切换前会先问你需要抓网络资料的小工具

HTTPS 小应用会让网页把你输入的东西传给别的服务器，只在你信任文件来源时再开。一般的小工具用“离线小应用”就够了。

5. 资料会留著，也可以清掉

每一件交付有自己的储存空间。小工具用 localStorage 存的东西，下次在过目打开同一件时还在；不同的小工具之间不会互相看到。

想从头来，按右上角的“⋯”，选“清除这份文件的小应用资料”。这只清掉小工具存的资料，文件本身不会删。

过目可以在设置里打开“专注计时.html”这个范例，切到“离线小应用”就能试试看。

6. 做不到的事

为了让不明来源的文件打开也安全，过目对网页程序有几个限制：

  • 从网络载入的程序（CDN、外部程序库）不会执行，要写在文件里。
  • 不能开新窗口、不能嵌入其他网页，也不能跳到外部网址。
  • 表单不会送出到网络上。
  • 只有切到“HTTPS 小应用”并同意后，才能联网。

小工具需要好几个文件（例如图片、另外的 CSS）时，请 AI 打包成 ZIP，里面放一个 index.html。整包分享到过目，会先打开 index.html，同一包里的文件可以互相引用。

7. 不好用？留备注请 AI 改

第一版常常有小地方要调，例如按钮太小、数字没对齐。看到就在过目加一则备注，写“哪里＋要改成怎样”。全部看完，用“退件单”把还没解决的备注整理成一段文字，贴回和 AI 的对话，请它改。

改好的文件用同一个档名送回过目，会记成第 2 版，可以对照上次的备注一条一条看。这部分的做法在另一篇文章有写。

过目需要 iOS 18 以上。免费版可以存 10 件、有横幅广告；Pro 不限件数、没有广告。文件和小工具的资料都存在你自己的手机或 iCloud 云碟，不会传到我的服务器，详见隐私权政策。

8. 常见问题

为什么打开 HTML 档，按钮按了没反应？

过目打开 HTML 默认是“安全预览”，不执行网页里的程序。叫出完整介面，在上方“执行模式”选“离线小应用”，页面重新载入后就能操作。

小工具存的资料会不会不见？

用 localStorage 存的资料，会留在那一件交付里，下次打开还在。要清掉时，在“⋯”选“清除这份文件的小应用资料”。

AI 做的小工具用了外部程序库，在过目里跑不起来？

从网络载入的程序不会执行。请 AI 改成单一 HTML 档，把需要的程序直接写在文件里，不要用 CDN。

小工具需要联网抓资料可以吗？

可以切到“HTTPS 小应用”，切换前过目会先问你。网页程序可能把内容或你输入的资料传给别的服务器，只在信任文件来源时使用。
