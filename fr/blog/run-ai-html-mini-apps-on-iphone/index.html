Exécuter hors ligne des mini-apps HTML créées par IA sur iPhone

Demandez à une IA de créer un petit outil, comme un minuteur, un suivi de dépenses ou une checklist, et vous obtiendrez un fichier HTML en quelques phrases. La dernière étape est souvent la plus difficile : l’ouvrir sur votre téléphone, faire fonctionner les boutons et conserver vos données pour la prochaine fois. Demandez à l’IA de tout mettre dans un seul fichier HTML, partagez-le vers Guomu et passez en mode “Offline mini app” pour le lancer. Il reste hors ligne et ses données restent liées à cet envoi.

Je suis Sona Orbit, développeur indépendant de Guomu (過目). Voici comment j’utilise des outils créés par une IA sur mon téléphone. Pour le détail des fonctionnalités de Guomu, référez-vous à ce site et à la version 1.0 de l’app (novembre 2026).

1. Le plus dur : ouvrir un outil créé par une IA

Le HTML ne sert pas qu’aux pages web. Ce peut aussi être un petit programme avec des boutons qui fait des calculs et retient ce que vous saisissez. Claude, Gemini et d’autres applications d’IA similaires peuvent généralement en créer un à partir d’une courte demande.

La difficulté est de l’utiliser sur votre téléphone. Il se présente parfois comme un long bloc de code dans une conversation. Même si vous l’enregistrez en tant que fichier, il vous faut un endroit où l’ouvrir et l’exécuter. Pour que l’outil soit utile, ses boutons doivent fonctionner et ses chiffres doivent rester enregistrés.

2. Des outils que vous pouvez demander à une IA

Les bons candidats tiennent sur un seul écran, ont quelques boutons et conservent des données rien que pour vous. Par exemple :

  • Un minuteur Pomodoro, un minuteur à thé ou un chronomètre à intervalles
  • Un suivi de dépenses simple : saisissez un montant et une catégorie, puis voyez le total
  • Une checklist quotidienne pour boire de l’eau, prendre un médicament ou réviser du vocabulaire
  • Des cartes mémoire à retourner, qui réaffichent les cartes ratées
  • Un outil pour partager l’addition ou un convertisseur de devises (vous saisissez le taux de change)
  • Un tirage au sort, un lanceur de dés ou un roulement d’équipe

3. Comment rédiger un prompt utilisable

En plus de décrire l’outil voulu, ajoutez ces consignes pour aider le fichier à fonctionner sur votre téléphone :

  • « Fais-en un seul fichier HTML, avec le CSS et le JavaScript dans ce même fichier. » Un fichier unique est plus facile à partager, sans pièces manquantes.
  • « N’utilise pas de bibliothèques externes ni de CDN. » Le code chargé depuis Internet ne s’exécutera pas dans Guomu. Le code écrit directement dans le fichier fonctionnera.
  • « Enregistre les données dans localStorage. » Cela conserve ce que vous avez saisi lorsque vous fermez puis rouvrez l’outil.
  • « Conçois-le pour un iPhone en mode portrait, avec de grands boutons. »

4. L’ouvrir dans Guomu avec Offline mini app

Quand le fichier est prêt, touchez Partager dans l’application d’IA et choisissez Guomu pour le recevoir comme un envoi. Changez ensuite de mode :

  1. Ouvrez l’envoi. Il s’affiche en plein écran. Touchez le bouton carré en bas à droite pour afficher toute l’interface.
  2. En haut, touchez “Run mode”.
  3. Choisissez “Offline mini app”. La page se recharge et ses boutons fonctionnent.

Guomu propose trois modes pour ouvrir le HTML. Il démarre dans le mode le plus prudent. Vous devez changer de mode vous-même pour exécuter du code, et chaque fois que vous ouvrez le fichier, il démarre en “Safe preview” :

ModeExécute le codeAccès à InternetIdéal pour
Safe preview (par défaut)NonNonLes rapports et documents que vous voulez seulement lire
Offline mini appExécute le code du fichierNonLes minuteurs, suivis de dépenses et checklists
HTTPS mini appExécute le code du fichierPeut se connecter en HTTPS après votre confirmationLes outils qui doivent récupérer des données en ligne

Le mode HTTPS mini app peut permettre à une page d’envoyer ce que vous saisissez vers un autre serveur. Utilisez-le uniquement lorsque vous faites confiance à la source du fichier. “Offline mini app” suffit pour la plupart des petits outils.

5. Conserver ou effacer vos données

Chaque envoi dispose de son propre stockage. Les données qu’un outil enregistre dans localStorage sont toujours là la prochaine fois que vous ouvrez cet envoi dans Guomu. Les autres outils ne peuvent pas les voir.

Pour repartir de zéro, touchez “⋯” en haut à droite et choisissez “Clear this file's mini app data”. Cela efface les données enregistrées par l’outil mais ne supprime pas le fichier.

Vous pouvez ouvrir l’exemple “Focus Timer.html” dans les réglages de Guomu et passer en “Offline mini app” pour l’essayer.

6. Ce que ces outils ne peuvent pas faire

Guomu limite ce que le code web peut faire afin que vous puissiez ouvrir des fichiers de sources inconnues de façon plus sûre :

  • Le code chargé depuis Internet, y compris les CDN et les bibliothèques externes, ne s’exécutera pas. Mettez-le dans le fichier.
  • La page ne peut pas ouvrir de nouvelles fenêtres, intégrer d’autres pages web ni naviguer vers des URL externes.
  • Les formulaires ne seront pas envoyés sur Internet.
  • La page ne peut se connecter à Internet qu’après être passé en “HTTPS mini app” et avoir confirmé.

Si un outil a besoin de plusieurs fichiers, comme des images ou un fichier CSS séparé, demandez à l’IA de les regrouper dans un ZIP contenant un fichier index.html. Partagez le ZIP entier vers Guomu. Il ouvre d’abord index.html, et les fichiers d’un même paquet peuvent faire référence les uns aux autres.

7. Laisser des notes et demander des corrections à l’IA

La première version demande souvent de petits ajustements, comme un bouton plus grand ou un meilleur alignement des chiffres. Quand vous repérez quelque chose, ajoutez une note dans Guomu qui indique ce qu’il faut modifier et comment. Une fois votre relecture terminée, utilisez “Return slip” pour rassembler les notes non résolues en un seul texte. Collez-le dans votre conversation avec l’IA et demandez une correction.

Envoyez le fichier révisé vers Guomu avec le même nom de fichier. Il devient la version 2, ce qui vous permet de vérifier vos notes précédentes une par une. J’explique ce processus dans un autre article.

Guomu nécessite iOS 18 ou une version ultérieure. La version gratuite permet de conserver 10 envois et affiche une bannière publicitaire. La version Pro supprime la limite d’envois et les publicités. Vos fichiers et les données des mini-apps restent sur votre téléphone ou dans votre iCloud Drive, pas sur mon serveur. Consultez la politique de confidentialité pour plus de détails.

8. Questions fréquentes

Pourquoi les boutons ne fonctionnent-ils pas quand j’ouvre un fichier HTML ?

Guomu ouvre par défaut le HTML en mode “Safe preview”, qui n’exécute pas le code de la page. Affichez l’interface complète, touchez “Run mode” en haut et choisissez “Offline mini app”. La page se recharge et vous pouvez utiliser les boutons.

Vais-je perdre les données enregistrées par une mini-app ?

Les données enregistrées dans localStorage restent liées à cet envoi et sont toujours là quand vous le rouvrez. Pour les effacer, touchez “⋯” et choisissez “Clear this file's mini app data”.

Pourquoi un outil créé par une IA qui utilise une bibliothèque externe ne fonctionne-t-il pas dans Guomu ?

Le code chargé depuis Internet ne s’exécute pas. Demandez à l’IA de créer un seul fichier HTML contenant tout le code nécessaire, sans CDN.

Une mini-app peut-elle récupérer des données depuis Internet ?

Vous pouvez passer en mode “HTTPS mini app”. Guomu vous demande d’abord de confirmer. Le code de la page peut envoyer son contenu ou les données que vous saisissez vers un autre serveur, n’utilisez donc ce mode que si vous faites confiance à la source du fichier.
