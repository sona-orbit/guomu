iPhone App

エージェントが作ったファイルを、iPhone で確認する。

Claude や Gemini などのアプリが作ったものを読み、直してほしい箇所に印をつけて、修正点を一つの文章にして返します。

  • 無料ダウンロード
  • 38種類の形式
  • アカウント登録なし

できること

01受け取り・プレビュー

共有メニューから受け取って、全画面で読む

エージェントのアプリで共有をタップし、過目を選び、ラベルを付けて受け取ります。ラベルにはまず候補が入ります。リンクのドメインや、エージェントがファイルに書いた目印から推測し、わからなければ前回のラベルが入ります。書き換えても、空欄のままでもかまいません。「ファイル」App からの読み込みもできます。

HTML、Markdown、PDF、画像、音声と動画、CSV、JSON、ZIP、字幕、フォントなどを開けます。開くと全画面表示になり、右下にある3つの四角いボタンで、前の画面に戻る、確認済みにする、すべての操作を表示する、ができます。片手の親指が届く位置です。大きなファイルは、開く前にサイズを知らせます。

02チェック

メモを残して、差し戻し票を作る

直したい箇所があれば、場所と直す内容をメモに書きます。状態は「未確認」「要修正」「確認済み」の3つです。

差し戻し票は、まだ解決していないメモを一つの文章にまとめたものです。コピーするか、共有してエージェントとの会話に戻します。同じ名前のファイルがもう一度届くと、第2版として記録されます。

03投稿

SNS の投稿をリンクから保存する

Threads、X、Instagram、Facebook の投稿リンクを共有すると、投稿者、本文、1枚目の画像を保存します。

読み取れるのは公開投稿だけです。画像は1枚目のみで、動画は保存しません。X の場合、保存される画像は投稿者のプロフィール画像です。ログインしないと見られない投稿は読み取れません。

04フォルダ

ラベルがそのままフォルダになる

ファイルごとにラベルは一つで、ラベルがそのままフォルダになります。ファイルは iCloud Drive の「過目」フォルダに保存され、iPhone の「ファイル」App や Mac からも見られます。iCloud にサインインしていないときは iPhone 内に保存されます。

フォルダ画面では、閲覧、移動、削除、ファイル名の検索ができます。受領票の一覧は日付ごとか形式ごとにまとめられます。

こんなときに

  1. エージェントに週報を HTML で作ってもらい、通勤中に読む。表の数字が一つ違っていたのでメモを残し、席に着いてから差し戻し票を会話に貼る。
  2. PDF、CSV、Markdown がまとめて届いたので、一つずつ開き、読み終えたものから確認済みにしていく。
  3. エージェントに参考として渡したい Threads の投稿を見つけたので、ひとまず過目に共有して取っておく。
  4. 何度か直してもらっている資料の第2版が届いたので、前回のメモどおりに直っているかを見る。

できないこと

  • iOS は共有元のアプリを過目に伝えないため、ラベルは推測です。
  • SKP、DWG、RAR、7Z など、開けない形式があります。その場合は開けないことを表示し、別のアプリに渡すか、元のデータをそのまま表示できます。
  • HTML は初期設定ではスクリプトを実行せず、ネットワークにも接続しません。

無料版と Pro

無料版

  • 保存できるのは10件まで
  • 受領票の一覧の下にバナー広告
  • ほかの機能は同じように使えます

Pro

  • 件数の上限なし
  • 広告なし
  • 見た目を受領票のほかに「和紙白」「レトロ」に変更可能

Pro は月額、年額、買い切りの3種類です。価格は App Store の表示をご確認ください。

インストールしたら、次にエージェントからファイルを受け取るとき、共有メニューで過目を選んでください。
