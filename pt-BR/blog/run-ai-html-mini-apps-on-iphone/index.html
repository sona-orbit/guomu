Como rodar miniapps HTML feitos por IA offline no iPhone

Peça a uma IA para criar uma pequena ferramenta, como um timer, controle de gastos ou checklist, e você recebe um arquivo HTML em poucas frases. O último passo costuma ser o mais difícil: abrir no celular, fazer os botões funcionarem e manter seus dados para a próxima vez. Peça à IA para colocar tudo em um único arquivo HTML, compartilhe com o Guomu e mude para “Offline mini app” para executá-lo. Ele fica offline, e os dados ficam salvos naquela entrega.

Sou Sona Orbit, pessoa desenvolvedora independente do Guomu (過目). É assim que uso ferramentas feitas por IA no meu celular. Para detalhes sobre os recursos do Guomu, consulte este site e o App 1.0 (novembro de 2026).

1. A parte difícil: abrir uma ferramenta feita por IA

HTML não serve só para páginas da web. Ele também pode ser um pequeno programa com botões que faz cálculos e lembra o que você digita. O Claude, o Gemini e outros apps de IA parecidos costumam criar um a partir de um pedido curto.

A parte complicada é usar isso no celular. Pode ser um longo bloco de código em um chat. Mesmo se você salvar como arquivo, precisa de um lugar para abrir e executar. Para a ferramenta ser útil, os botões precisam funcionar e os números precisam continuar lá.

2. Ferramentas que você pode pedir para uma IA criar

Bons exemplos cabem em uma tela, têm poucos botões e guardam dados só para você. Por exemplo:

  • Um timer Pomodoro, timer para chá ou timer de intervalos
  • Um controle de gastos simples: digite um valor e uma categoria, depois veja o total
  • Um checklist diário para beber água, tomar remédio ou praticar vocabulário
  • Flashcards que você pode virar, mostrando novamente os cartões que você errou
  • Um divisor de conta ou conversor de moedas (você digita a taxa de câmbio)
  • Um sorteador, rolador de dados ou escala de revezamento

3. Como escrever um comando que funcione

Junto com a descrição da ferramenta que você quer, adicione estas instruções para ajudar o arquivo a rodar no seu celular:

  • “Faça em um único arquivo HTML, com o CSS e o JavaScript nesse mesmo arquivo.” Um arquivo só é mais fácil de compartilhar, sem peças faltando.
  • “Não use bibliotecas externas nem CDN.” Códigos carregados da internet não vão rodar no Guomu. Códigos escritos dentro do arquivo vão.
  • “Salve os dados no localStorage.” Isso mantém o que você digitou quando fecha e abre a ferramenta de novo.
  • “Projete para um iPhone na vertical, com botões grandes.”

4. Abra no Guomu com Offline mini app

Quando o arquivo estiver pronto, toque em Compartilhar no app de IA e escolha o Guomu para recebê-lo como uma entrega. Depois, mude o modo:

  1. Abra a entrega. Ela inicia em tela cheia. Toque no botão quadrado no canto inferior direito para mostrar a interface completa.
  2. No topo, toque em “Run mode”.
  3. Escolha “Offline mini app”. A página recarrega e os botões passam a funcionar.

O Guomu tem três modos para abrir HTML. Ele começa no modo mais cauteloso. Você precisa mudar de modo por conta própria para rodar código e, toda vez que você abre o arquivo, ele começa em “Safe preview”:

ModoRoda códigoAcesso à internetBom para
Safe preview (padrão)NãoNãoRelatórios e documentos que você só precisa ler
Offline mini appRoda o código do arquivoNãoTimers, controles de gastos e checklists
HTTPS mini appRoda o código do arquivoPode conectar via HTTPS após sua confirmaçãoFerramentas que precisam buscar dados online

O modo HTTPS mini app pode permitir que uma página envie o que você digita para outro servidor. Use apenas quando confiar na origem do arquivo. “Offline mini app” é suficiente para a maioria das pequenas ferramentas.

5. Manter ou limpar seus dados

Cada entrega tem seu próprio armazenamento. Os dados que uma ferramenta salva no localStorage continuam lá na próxima vez que você abrir aquela entrega no Guomu. Outras ferramentas não conseguem vê-los.

Para começar do zero, toque em “⋯” no canto superior direito e escolha “Clear this file's mini app data”. Isso limpa os dados salvos da ferramenta, mas não apaga o arquivo.

Você pode abrir o exemplo “Focus Timer.html” nos ajustes do Guomu e mudar para “Offline mini app” para testar.

6. O que essas ferramentas não podem fazer

O Guomu limita o que o código web pode fazer para que você possa abrir arquivos de fontes desconhecidas com mais segurança:

  • Códigos carregados da internet, incluindo CDNs e bibliotecas externas, não vão rodar. Coloque tudo dentro do arquivo.
  • A página não pode abrir novas janelas, incorporar outras páginas da web nem navegar para URLs externos.
  • Formulários não serão enviados para a internet.
  • A página só pode se conectar à internet depois que você mudar para “HTTPS mini app” e confirmar.

Se uma ferramenta precisar de vários arquivos, como imagens ou um arquivo CSS separado, peça à IA para colocá-los em um pacote ZIP com um index.html dentro. Compartilhe o ZIP inteiro com o Guomu. Ele abre o index.html primeiro, e os arquivos no mesmo pacote podem fazer referência uns aos outros.

7. Deixe notas e peça correções à IA

A primeira versão costuma precisar de pequenos ajustes, como um botão maior ou um melhor alinhamento dos números. Quando notar algo, adicione uma nota no Guomu dizendo o que precisa mudar e como. Quando terminar de revisar, use “Return slip” para reunir as notas não resolvidas em um único texto. Cole na sua conversa com a IA e peça uma correção.

Envie o arquivo revisado para o Guomu com o mesmo nome. Ele vira a versão 2, assim você pode conferir com suas notas anteriores uma por uma. Explico esse processo em outro artigo.

O Guomu requer iOS 18 ou posterior. A versão gratuita permite salvar 10 entregas e tem um banner de anúncio. O Pro remove o limite de entregas e os anúncios. Seus arquivos e dados de miniapps ficam no seu celular ou no seu iCloud Drive, não no meu servidor. Veja a política de privacidade para mais detalhes.

8. Perguntas frequentes

Por que os botões não funcionam quando abro um arquivo HTML?

O Guomu abre HTML em “Safe preview” por padrão, o que não roda o código na página. Mostre a interface completa, toque em “Run mode” no topo e escolha “Offline mini app”. A página recarrega e você pode usar os botões.

Vou perder os dados salvos por um miniapp?

Os dados salvos no localStorage ficam com aquela entrega e continuam lá quando você a abre novamente. Para limpar, toque em “⋯” e escolha “Clear this file's mini app data”.

Por que uma ferramenta feita por IA que usa uma biblioteca externa não roda no Guomu?

Códigos carregados da internet não rodam. Peça à IA para fazer um único arquivo HTML com todo o código necessário escrito dentro dele, sem CDN.

Um miniapp pode buscar dados da internet?

Você pode mudar para “HTTPS mini app”. O Guomu pede para você confirmar primeiro. O código na página pode enviar seu conteúdo ou os dados que você digitar para outro servidor, então use este modo apenas quando confiar na origem do arquivo.
