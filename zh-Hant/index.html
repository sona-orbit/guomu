iPhone App

Agent 做的檔案，在 iPhone 上檢查。

看 Claude、Gemini 這類 App 做出來的東西，標出要改的地方，再把要改的事整理成一段文字交回去。

  • 免費下載
  • 38 種格式
  • 不用註冊帳號

功能

01收件・預覽

從分享選單收進來，全螢幕看

在 Agent 的 App 裡按分享，選過目，填標籤，按「簽收」。標籤會先自動猜：看網址的網域、看檔案裡 Agent 自己寫的標記，猜不到就帶入上次用的。可以改，也可以不標。「檔案」App 裡的檔案也能匯入。

HTML、Markdown、PDF、圖片、音檔與影片、CSV、JSON、ZIP、字幕、字型都打得開。打開後是全螢幕；右下角三顆方鈕分別是回上頁、標為已過目、叫出完整介面，單手拇指按得到。大檔開啟前會先提醒大小。

02複核

留備註，開退件單

看到要改的地方就加一則備註，寫位置和要改什麼。每件交付有三種狀態：待看、要修、已過目。

「退件單」把還沒解決的備註整理成一段文字，可以複製，或分享回和 Agent 的對話。改好的同名檔案再送進來，會標成第 2 版。

03貼文

從連結存下社群貼文

從 Threads、X、Instagram、Facebook 分享一則貼文的連結進來，會存下作者、內文和第一張圖。

只讀得到公開貼文。圖只存第一張，不存影片；X 存到的圖是作者頭像。要登入才看得到的貼文讀不到。

04整理

標籤就是資料夾

一件交付一個標籤，標籤就是資料夾。檔案存在你 iCloud 雲碟的「過目」資料夾，iPhone 的「檔案」App 和 Mac 都看得到；沒登入 iCloud 時存在手機裡。

資料夾頁可以瀏覽、搬移、刪除、搜尋檔名。簽收單可以依日期或格式分組。

這些時候用得到

  1. 請 Agent 把週報做成 HTML，通勤時打開看。表格裡有一個數字不對，留一則備註，到座位上再把退件單貼回對話。
  2. Agent 一次交來 PDF、CSV、Markdown，一份一份打開看，看完的標成已過目。
  3. 滑 Threads 看到一則想給 Agent 參考的貼文，先分享進過目存著。
  4. 改了幾輪的文件送來第 2 版，對照上次的備註，看有沒有照著改。

限制

  • iOS 不會告訴過目檔案是從哪個 App 分享來的，所以標籤是猜的。
  • 有些格式打不開，例如 SKP、DWG、RAR、7Z。過目會說明打不開，可以轉給別的 App 開，或看原始內容。
  • HTML 預設不執行頁面裡的程式，也不連網。

免費版與 Pro

免費版

  • 最多存 10 件
  • 簽收單下方有橫幅廣告
  • 其他功能都一樣能用

Pro

  • 不限件數
  • 沒有廣告
  • 外觀除了簽收單，還能換成「和紙白」「復古」

Pro 有月訂、年訂、買斷三種，價格以 App Store 顯示為準。
