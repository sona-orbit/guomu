在手機上請 Claude、Gemini 做的檔案，怎麼檢查、再請它改？

在手機上請 Agent 做東西，最難的不是請它做，而是檢查：檔案擠在對話裡看不清楚，看到要改的地方又一次只能講一點。比較順的做法是請它輸出成檔案、全螢幕看、邊看邊記下「位置＋要改什麼」，最後把所有修改整理成一段文字一次交回，改好的第 2 版再對照上次的筆記。

我是 Sona Orbit，一個人開發過目的獨立開發者。這篇是我自己在手機上檢查 Agent 產出的做法；過目的功能以本站說明為準（2026 年 11 月）。

1. 請 Agent 輸出成檔案，不要只貼在對話裡

週報、表格、簡單的網頁，如果直接貼在對話裡，手機畫面窄，表格會被擠壞，長文件也很難前後對照。請 Agent 做成檔案，例如 HTML、Markdown、PDF 或 CSV，看起來會清楚很多。

提示詞可以直接寫：「做成一個 HTML 檔給我」或「輸出成 Markdown 檔」。

2. 全螢幕看，一次看一件

檔案做好後，用分享選單送到可以預覽的地方，例如 iPhone 的「檔案」App，用全螢幕打開。

Agent 一次交好幾個檔案時，一份一份看，看完的就標記起來，免得漏看或重看。

3. 邊看邊記：位置＋要改什麼

看到要改的地方當下就記，不要等全部看完再回想。每一則寫兩件事：

  • 位置：第幾段、哪一張表、哪一欄。
  • 要改什麼：講結果，不講感覺。「第 3 列的金額應該是 12,400」比「數字怪怪的」好改。

一則只寫一件事。這樣 Agent 改的時候不會漏，你之後對照也容易。

4. 整理成一段文字，一次交回

看完再把所有筆記整理成一段文字，編號列出，一次貼回和 Agent 的對話。一次給完比較不會改了這裡、又動壞那裡，也省得來回好幾輪。

寫法例子
不好改「表格有點問題，再看一下」
好改「1. 第二張表第 3 列金額改成 12,400。2. 標題的日期改成 11 月 16 日。3. 結論那段刪掉最後一句。」

5. 第 2 版回來，對照上次的筆記

改好的檔案送回來時，拿上次的筆記一條一條對：哪幾條改好了，哪幾條沒改或改錯。沒改好的留著，下一輪再交回去。

6. 我把這套流程做成了過目

上面這些用「檔案」App 加備忘錄也做得到，只是要在幾個 App 之間切來切去。所以我做了 過目，把它們放在同一個地方：

  • 在 Agent 的 App 裡按分享、選過目，檔案就收進來；HTML、Markdown、PDF、圖片、CSV 等 38 種格式都能全螢幕看。
  • 看到要改的地方就加一則備註；每件交付有「待看、要修、已過目」三種狀態。
  • 「退件單」會把還沒解決的備註整理成一段文字，可以複製或分享回對話。
  • 同名檔案再送進來，會標成第 2 版，方便對照上次的備註。

過目需要 iOS 18 以上，免費版可以存 10 件、有橫幅廣告；Pro 不限件數、沒有廣告。檔案和備註存在你自己的 iCloud 雲碟或手機裡，不會傳到我們的伺服器，詳見隱私權政策。

7. 常見問題

為什麼要請 Agent 輸出成檔案？

手機畫面窄，表格、長文件直接貼在對話裡容易擠壞，也不好前後對照。做成 HTML、Markdown、PDF 這類檔案，可以全螢幕看。

修改要一次交回，還是看到一條講一條？

建議看完再一次交回，編號列出。一次給完，Agent 比較不會改了這裡又動壞那裡，也比較少來回。

過目怎麼知道檔案是哪個 Agent 做的？

iOS 不會告訴過目檔案是從哪個 App 分享來的，所以標籤是猜的：看網址的網域、看檔案裡 Agent 寫的標記，猜不到就帶入上次用的。收件前可以改。

過目打不開的格式怎麼辦？

像 SKP、DWG、RAR、7Z 這類格式打不開，過目會說明，可以轉給別的 App 開，或看原始內容。
