iPhone App

Files your agent made,checked on iPhone.

Read what Claude, Gemini or a similar app produced, mark what needs changing, and hand the changes back as one piece of text.

  • Free download
  • 38 file formats
  • No account

What it does

01Receive · Preview

Share it in, read it full screen

In the agent's app, tap Share, choose Guomu, add a label and confirm. Guomu fills in a label first, from the link's domain or a tag the agent wrote into the file, and otherwise uses the last label you chose. You can change it or leave it empty. Files can also be imported from the Files app.

HTML, Markdown, PDF, images, audio and video, CSV, JSON, ZIP, subtitles and fonts all open. Files open full screen. Three square buttons in the bottom-right corner go back, mark the file as reviewed, or bring up the full controls, and your thumb reaches them with one hand. Before a large file opens, Guomu shows its size.

02Review

Leave notes, then send a return slip

When something needs fixing, add a note that says where it is and what to change. Each delivery has one of three statuses: to review, with notes, reviewed.

The return slip gathers the open notes into one piece of text, which you copy or share back into the conversation with the agent. When a file with the same name comes in again, it is marked as version 2.

03Posts

Save a post from its link

Share a post's link from Threads, X, Instagram or Facebook, and Guomu saves the author, the text and the first image.

Only public posts can be read. Only the first image is kept and videos are not saved; for X, the saved image is the author's profile picture. Posts that need a login cannot be read.

04Folders

Each label is a folder

Every delivery has one label, and the label is its folder. Files are stored in the 過目 (Guomu) folder in your iCloud Drive, so the Files app on iPhone and your Mac can see them. Without iCloud, they stay on the phone.

On the folder page you can browse, move, delete and search by file name. The receipt list can be grouped by date or by format.

When it helps

  1. An agent turns this week's report into HTML. You read it on the train, see a wrong number in a table, leave a note, and paste the return slip into the chat once you are at your desk.
  2. The agent hands over a PDF, a CSV and a Markdown file together. You open them one at a time and mark each one as reviewed.
  3. You find a Threads post you want the agent to use as a reference, and share it into Guomu to keep it for later.
  4. A document that has been through a few rounds comes back as version 2, and you check it against your last notes.

Limits

  • iOS does not tell Guomu which app shared a file, so the label is a guess.
  • Some formats cannot be opened, such as SKP, DWG, RAR and 7Z. Guomu says so, and you can pass the file to another app or view its raw contents.
  • By default, HTML files open without running their scripts and without network access.

Free and Pro

Free

  • Keeps up to 10 deliveries
  • A banner ad below the receipt list
  • Everything else works the same

Pro

  • No limit on deliveries
  • No ads
  • Two more looks besides the receipt: Washi White and Retro

Pro comes as a monthly or yearly subscription, or a one-time purchase. Prices are as shown on the App Store.

After installing, choose Guomu in the share sheet the next time an agent gives you a file.
