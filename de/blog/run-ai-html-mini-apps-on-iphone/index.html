KI-erstellte HTML-Mini-Apps auf dem iPhone offline nutzen

Wenn du eine KI nach einem kleinen Werkzeug fragst – etwa einem Timer, einem Ausgabenrechner oder einer Checkliste –, bekommst du nach wenigen Sätzen eine HTML-Datei. Der letzte Schritt ist oft der schwierigste: die Datei auf dem iPhone öffnen, die Buttons zum Laufen bringen und deine Eingaben fürs nächste Mal speichern. Bitte die KI, alles in eine einzige HTML-Datei zu packen, teile sie mit Guomu und wechsle zu „Offline-Mini-App“, um sie auszuführen. Sie läuft offline und ihre Daten bleiben bei dieser Lieferung.

Ich bin Sona Orbit, Solo-Entwickler von Guomu (過目). So nutze ich von einer KI erstellte Werkzeuge auf meinem iPhone. Details zu den Funktionen von Guomu findest du auf dieser Website und in App-Version 1.0.2 (November 2026).

1. Der schwierige Teil: ein KI-Werkzeug öffnen

HTML ist nicht nur für Webseiten da. Es kann auch ein kleines Programm mit Buttons sein, das rechnet und sich deine Eingaben merkt. Claude, Gemini und ähnliche KI-Apps erstellen so etwas meist schon auf eine kurze Anfrage hin.

Knifflig wird es erst, wenn du es auf dem Smartphone nutzen willst. Oft ist es nur ein langer Codeblock im Chat. Selbst wenn du ihn als Datei speicherst, brauchst du einen Ort, um sie zu öffnen und auszuführen. Damit das Werkzeug im Alltag hilft, müssen die Buttons funktionieren und deine Zahlen erhalten bleiben.

2. Werkzeuge, die du dir von einer KI bauen lassen kannst

Gut geeignet sind kleine Helfer, die auf einen Bildschirm passen, ein paar Buttons haben und Daten nur für dich speichern. Zum Beispiel:

  • Ein Pomodoro-Timer, Teetimer oder Intervalltimer
  • Ein einfacher Ausgabenrechner: Betrag und Kategorie eingeben und die Summe sehen
  • Eine tägliche Checkliste zum Wassertrinken, für Medikamente oder zum Vokabellernen
  • Karteikarten zum Umdrehen, bei denen nicht gewusste Karten erneut abgefragt werden
  • Ein Rechnungsaufteiler oder Währungsrechner (du gibst den Wechselkurs selbst ein)
  • Ein Zufallsgenerator, Würfel oder Schichtplaner

3. So schreibst du einen Prompt, der funktioniert

Beschreibe das gewünschte Werkzeug und füge diese Anweisungen hinzu, damit die Datei auf deinem iPhone läuft:

  • „Erstelle eine einzige HTML-Datei, in der auch das gesamte CSS und JavaScript enthalten sind.“ Eine einzelne Datei lässt sich leichter teilen und es fehlen keine Teile.
  • „Verwende keine externen Bibliotheken und kein CDN.“ Aus dem Internet nachgeladener Code wird in Guomu nicht ausgeführt. Code direkt in der Datei schon.
  • „Speichere Daten in localStorage.“ So bleiben deine Eingaben erhalten, wenn du das Werkzeug schließt und später wieder öffnest.
  • „Gestalte es für ein iPhone im Hochformat mit großen Buttons.“
AnsatzBeispiel
Nur das Werkzeug nennen„Bau mir einen Ausgabenrechner.“
Brauchbare Details angeben„Bau mir einen Ausgabenrechner. Ich möchte einen Betrag eingeben und eine Kategorie wählen (Essen, Fahrtkosten oder Sonstiges). Zeige darunter die heutigen Einträge und die Gesamtsumme an. Erstelle eine einzige HTML-Datei mit CSS und JavaScript in derselben Datei. Verwende keine externen Bibliotheken. Speichere Daten in localStorage. Gestalte es für ein iPhone im Hochformat.“

4. In Guomu mit „Offline-Mini-App“ öffnen

Wenn die Datei fertig ist, tippe in der KI-App auf „Teilen“ und wähle Guomu, um sie als Lieferung zu empfangen. Wechsle dann den Modus:

  1. Öffne die Lieferung. Sie startet im Vollbildmodus. Tippe unten rechts auf den quadratischen Button, um die vollständige Oberfläche einzublenden.
  2. Tippe oben auf „Ausführung“.
  3. Wähle „Offline-Mini-App“. Die Seite lädt neu und die Buttons funktionieren.

Guomu hat drei Modi zum Öffnen von HTML. Standardmäßig startet der vorsichtigste Modus. Um Code auszuführen, musst du den Modus selbst umschalten, und bei jedem erneuten Öffnen startet die Datei wieder in „Sichere Vorschau“:

ModusFührt Code ausInternetzugangGeeignet für
Sichere Vorschau (Standard)NeinNeinBerichte und Dokumente, die du nur lesen willst
Offline-Mini-AppFührt Code in der Datei ausNeinTimer, Ausgabenrechner und Checklisten
HTTPS-Mini-AppFührt Code in der Datei ausVerbindung über HTTPS nach deiner BestätigungWerkzeuge, die Online-Daten abrufen müssen

Mit „HTTPS-Mini-App“ kann eine Seite deine Eingaben an einen fremden Server senden. Nutze diesen Modus nur, wenn du der Quelle der Datei vertraust. Für die meisten kleinen Werkzeuge reicht „Offline-Mini-App“ völlig aus.

5. Daten behalten oder löschen

Jede Lieferung hat ihren eigenen Speicher. Daten, die ein Werkzeug in localStorage ablegt, sind beim nächsten Öffnen dieser Lieferung in Guomu wieder da. Andere Werkzeuge können sie nicht einsehen.

Um von vorn zu beginnen, tippe oben rechts auf „⋯“ und wähle „Mini-App-Daten dieser Datei löschen“. Dadurch werden die gespeicherten Daten des Werkzeugs gelöscht, nicht aber die Datei selbst.

Zum Ausprobieren kannst du in den Einstellungen von Guomu die Beispieldatei „Fokus-Timer.html“ öffnen und auf „Offline-Mini-App“ umschalten.

6. Was diese Werkzeuge nicht können

Guomu schränkt ein, was Webcode tun darf, damit du Dateien aus unbekannten Quellen sicherer öffnen kannst:

  • Code aus dem Internet – einschließlich CDNs und externer Bibliotheken – wird nicht ausgeführt. Schreib ihn direkt in die Datei.
  • Die Seite kann keine neuen Fenster öffnen, keine anderen Webseiten einbetten und nicht zu externen URLs wechseln.
  • Formulare lassen sich nicht ins Internet absenden.
  • Die Seite kann sich erst mit dem Internet verbinden, nachdem du auf „HTTPS-Mini-App“ umgeschaltet und bestätigt hast.

Wenn ein Werkzeug mehrere Dateien benötigt, etwa Bilder oder eine separate CSS-Datei, bitte die KI, alles zusammen mit einer index.html in ein ZIP-Archiv zu packen. Teile die gesamte ZIP-Datei mit Guomu. Guomu öffnet zuerst die index.html, und Dateien im selben Paket können aufeinander verweisen.

7. Notizen hinterlassen und die KI um Korrekturen bitten

Die erste Version braucht oft noch kleine Anpassungen, wie einen größeren Button oder sauber ausgerichtete Zahlen. Wenn dir etwas auffällt, füge in Guomu eine Notiz hinzu, was wie geändert werden soll. Wenn du mit dem Prüfen fertig bist, fasse die offenen Notizen über „Rücksendeschein“ zu einem einzigen Text zusammen. Füge ihn in deinen Chat mit der KI ein und bitte um eine Korrektur.

Schicke die überarbeitete Datei unter demselben Dateinamen wieder an Guomu. Sie wird als Version 2 abgelegt, sodass du deine bisherigen Notizen Punkt für Punkt abgleichen kannst. Diesen Ablauf erkläre ich in einem weiteren Artikel.

Guomu setzt iOS 18 oder neuer voraus. In der kostenlosen Version kannst du bis zu 10 Lieferungen behalten und siehst ein Werbebanner. Pro hebt das Limit auf und entfernt die Werbung. Deine Dateien und Mini-App-Daten bleiben auf deinem iPhone oder in deinem iCloud Drive, nicht auf meinem Server. Details findest du in der Datenschutzerklärung.

8. Häufig gestellte Fragen

Warum funktionieren die Buttons nicht, wenn ich eine HTML-Datei öffne?

Guomu öffnet HTML standardmäßig im Modus „Sichere Vorschau“, der keinen Code auf der Seite ausführt. Blende die vollständige Oberfläche ein, tippe oben auf „Ausführung“ und wähle „Offline-Mini-App“. Die Seite lädt neu und du kannst die Buttons benutzen.

Gehen die von einer Mini-App gespeicherten Daten verloren?

In localStorage gespeicherte Daten bleiben bei dieser Lieferung und sind beim nächsten Öffnen wieder da. Um sie zu löschen, tippe auf „⋯“ und wähle „Mini-App-Daten dieser Datei löschen“.

Warum läuft ein KI-Werkzeug mit externer Bibliothek nicht in Guomu?

Aus dem Internet nachgeladener Code wird nicht ausgeführt. Bitte die KI, eine einzige HTML-Datei zu erstellen, die den gesamten benötigten Code direkt enthält, ohne CDN.

Kann eine Mini-App Daten aus dem Internet abrufen?

Du kannst zu „HTTPS-Mini-App“ wechseln. Guomu bittet dich zuvor um Bestätigung. Da Code auf der Seite Inhalte oder deine Eingaben an einen fremden Server senden kann, solltest du diesen Modus nur nutzen, wenn du der Quelle der Datei vertraust.
