How to Write AI Revision Notes That Get the Right Fixes: 5 Tips

You ask an AI to fix one number in a file, but it rewrites the whole thing and changes parts that were already right. Often, the revision note was too vague. For each note, say where the problem is, what is there now, and what you want instead. Keep each note to one change. Here are 5 ways to do that, with examples.

1. Point to the exact location

“The table on page 2 looks wrong” makes sense when you're looking at it. The AI only has the words you send. A precise location helps it leave the rest of the file alone.

File typeHow to describe the location
Reports, web pagesHeading text, table name, row and column, or button text
Documents, MarkdownSubheading, paragraph number, or the first few words of the sentence
Slides, PDFsPage number and the title on that page
Spreadsheets, CSVsColumn name and a value that identifies the row, such as “revenue in the 2026-11 row”

Quoting the original text is especially helpful. Paste the words you want changed so the AI can find that spot.

2. Say what it says now and what it should say

If you only write “the number is wrong,” the AI has to guess the right one. Give it both the current value and the correct value:

  • Vague: “The revenue looks wrong.”
  • Clear: “November revenue now says 120,000. It should say 12,000. There's an extra 0.”

If you don't know the right answer, say so: “This number doesn't match the subtotal above. Please calculate it again and show your work.” That asks the AI to check the number, not guess a replacement.

3. Put one change in each note

If one note contains three requests, the AI may miss one or two. It's harder for you to check them, too. Write a separate note for each location and change.

Then you can cross off each fix as you check it. Anything the AI missed will stand out, and you can send just those notes back for the next round.

4. Separate must-fix items from optional ones

Not every note has the same priority. Wrong numbers, factual errors, and missing sections need fixing. Smoother wording or a different color may be optional.

When you send your notes back, list “Must fix” items first, then “If there's time” items. This puts the important changes first and makes it easier to decide whether the new version is usable.

5. Explain how to check the fix

For some changes, it helps to say how you'll know the work is done:

  • “After the change, the total at the bottom of the table should equal the sum of the rows above.”
  • “Don't change any other paragraphs. Only edit paragraph 3.”
  • “When you're done, list every place you changed.”

That last request is useful. You can check the places the AI lists instead of rereading the whole file.

6. Put your notes together before sending them back

Write notes as you review the file. When you're ready, combine them into one message and paste it into the conversation:

OrderWhat to include
1One sentence identifying the file and its version
2Must-fix notes, one per line: location, current state, desired state
3Optional notes
4What should stay unchanged and how to check the fixes

When the new version comes back, check it against your list. Cross off the fixes and keep any unfinished notes for the next round.

7. How I do this in Guomu

The hardest parts of this process are taking notes while you review and putting them together afterward. I built those steps into Guomu, an iPhone app for files an AI agent makes on your phone:

  • In the agent app, tap Share and choose Guomu. The file comes in and opens full screen. You can open HTML, Markdown, PDF, images, CSV, and more.
  • When you find something to fix, tap “Add note” and write where it is and what should change. Each delivery has 3 states: “To review,” “Notes,” and “Reviewed.”
  • On the Receipt, you can group by “With notes” to see only deliveries that have notes. Tap a delivery to open its notes, or press and hold a row to preview them.
  • Tap “Return slip” to combine unresolved notes into one message. Copy it or share it back to the agent conversation. If you send in a revised file with the same name, Guomu marks it as version 2.

8. Frequently asked questions

Why did the AI rewrite the whole file when I asked for one change?

Often, the note doesn't say where the problem is or what should replace it. The AI ends up generating the file again. Give the location, the current text or value, and the result you want. Add “Don't change anything else.”

Should I send notes one at a time or all at once?

Write notes one at a time as you review, then combine them into one message to send back. If you send them separately, the AI only sees part of your feedback each time and may make inconsistent changes.

Can I circle the problem in a screenshot and send that to the AI?

Yes, if the AI can read images. Still write out what you want it to change to, so it doesn't have to guess.

What if it's still wrong after several rounds?

Gather only the notes that haven't been resolved and add “When you're done, list every place you changed.” If it keeps getting the same spot wrong, ask it to explain what it thinks you mean before it makes another change.
