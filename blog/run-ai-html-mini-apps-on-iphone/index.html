How to Run AI-Made HTML Mini Apps Offline on Your iPhone

Ask an AI to make a small tool, like a timer, expense tracker, or checklist, and you can get an HTML file in a few sentences. The last step is often the hard part: opening it on your phone, getting the buttons to work, and keeping your data for next time. Ask the AI to put everything in one HTML file, share it to Guomu, and switch to “Offline mini app” to run it. It stays offline, and its data stays with that delivery.

I’m Sona Orbit, the solo developer of Guomu (過目). This is how I use AI-made tools on my phone. For details about Guomu’s features, refer to this site and App 1.0 (November 2026).

1. The hard part: opening an AI-made tool

HTML is not just for web pages. It can also be a small program with buttons that does calculations and remembers what you enter. Claude, Gemini, and similar AI apps can usually make one from a short request.

The tricky part is using it on your phone. It may be a long block of code in a chat. Even if you save it as a file, you need somewhere to open and run it. For the tool to be useful, its buttons need to work and its numbers need to stay there.

2. Tools you can ask an AI to make

Good candidates fit on one screen, have a few buttons, and hold data just for you. For example:

  • A Pomodoro timer, tea timer, or interval timer
  • A simple expense tracker: enter an amount and category, then see the total
  • A daily checklist for drinking water, taking medication, or practicing vocabulary
  • Flashcards you can flip, with missed cards shown again
  • A bill splitter or currency converter (you enter the exchange rate)
  • A random picker, dice roller, or shift rotation

3. How to write a prompt you can use

Along with describing the tool you want, add these instructions to help the file run on your phone:

  • “Make it a single HTML file, with the CSS and JavaScript in that same file.” One file is easier to share, with no missing pieces.
  • “Do not use external libraries or a CDN.” Code loaded from the internet will not run in Guomu. Code written into the file will.
  • “Save data in localStorage.” That keeps what you entered when you close and reopen the tool.
  • “Design it for an iPhone in portrait orientation, with large buttons.”

4. Open it in Guomu with Offline mini app

When the file is ready, tap Share in the AI app and choose Guomu to receive it as a delivery. Then switch modes:

  1. Open the delivery. It starts in full screen. Tap the square button at the bottom right to show the full interface.
  2. At the top, tap “Run mode.”
  3. Choose “Offline mini app.” The page reloads, and its buttons work.

Guomu has three modes for opening HTML. It starts in the most cautious mode. You must switch modes yourself to run code, and every time you open the file, it starts in “Safe preview”:

Safe preview (default)NoNoReports and documents you only need to read
Offline mini appRuns code in the fileNoTimers, expense trackers, and checklists

HTTPS mini app can let a page send what you enter to another server. Use it only when you trust the file’s source. “Offline mini app” is enough for most small tools.

5. Keep or clear your data

Each delivery has its own storage. Data a tool saves in localStorage is there the next time you open that delivery in Guomu. Other tools cannot see it.

To start over, tap “⋯” at the top right and choose “Clear this file's mini app data.” This clears the tool’s saved data but does not delete the file.

You can open the sample “Focus Timer.html” in Guomu’s settings and switch to “Offline mini app” to try it.

6. What these tools cannot do

Guomu limits what web code can do so you can open files from unknown sources more safely:

  • Code loaded from the internet, including CDNs and external libraries, will not run. Put it in the file.
  • The page cannot open new windows, embed other web pages, or navigate to external URLs.
  • Forms will not submit to the internet.
  • The page can connect to the internet only after you switch to “HTTPS mini app” and confirm.

If a tool needs several files, such as images or a separate CSS file, ask the AI to package them in a ZIP with an index.html inside. Share the whole ZIP to Guomu. It opens index.html first, and files in the same package can refer to each other.

7. Leave notes and ask the AI for fixes

The first version often needs small changes, like a larger button or better number alignment. When you spot something, add a note in Guomu that says what needs changing and how. When you finish reviewing, use “Return slip” to collect unresolved notes into one piece of text. Paste it into your conversation with the AI and ask for a fix.

Send the revised file to Guomu with the same filename. It becomes version 2, so you can check it against your earlier notes one by one. I explain this process in another article.

Guomu requires iOS 18 or later. The free version lets you save 10 deliveries and has a banner ad. Pro removes the delivery limit and ads. Your files and mini app data stay on your phone or in your iCloud Drive, not on my server. See the privacy policy for details.

8. Frequently asked questions

Why don’t the buttons work when I open an HTML file?

Guomu opens HTML in “Safe preview” by default, which does not run code in the page. Show the full interface, tap “Run mode” at the top, and choose “Offline mini app.” The page reloads, and you can use the buttons.

Will I lose the data saved by a mini app?

Data saved in localStorage stays with that delivery and is there when you open it again. To clear it, tap “⋯” and choose “Clear this file's mini app data.”

Why won’t an AI-made tool that uses an external library run in Guomu?

Code loaded from the internet will not run. Ask the AI to make a single HTML file with all the needed code written into it, without a CDN.

Can a mini app fetch data from the internet?

You can switch to “HTTPS mini app.” Guomu asks you to confirm first. Code in the page may send its contents or data you enter to another server, so use this mode only when you trust the file’s source.
